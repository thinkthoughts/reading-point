# Reading Point Brand

This directory contains the visual identity and style specifications for **Reading Point**.

Reading Point uses a small, reproducible visual system derived from its mathematical and engineering work. The core mark is an eight-position ring representing the reduced residue classes modulo 30:

`{1, 7, 11, 13, 17, 19, 23, 29}`

One position may be highlighted as a **reading point**.

## Contents

* `logo/` — canonical Reading Point logo and badge assets
* `colors.css` — initial brand and operational color tokens
* `STYLE.md` — visual and semantic usage specification

## Design principles

The visual system separates three kinds of information:

* **Geometry identifies Reading Point.**
* **Pink or blue identifies the brand interface.**
* **Red, yellow, and green identify operational states.**

The eight-position ring specifies mathematical structure. A highlighted position identifies a reading point without implying that the highlighted residue has a privileged mathematical status.

## Modes

Dark interfaces use the Reading Point pink accent.

Light interfaces use the Reading Point blue accent.

Operational red, yellow, and green remain available in either mode and retain their state meanings.

## Canonical source

The SVG logo assets are the canonical versions of the mark. Raster versions should be generated from those sources for avatars, badges, previews, or other fixed-size uses.
